1 · The big idea

Problem: in a Binary Search Tree (BST), find the smallest difference between the values of any two nodes.

BST rule: for every node, everything in its left subtree is smaller and everything in its right subtree is bigger.

Inorder traversal visits Left → Root → Right. Because left values are smaller and right values are bigger, we always meet the values in sorted order. Press the button and watch.

The plan

  1. Walk the tree inorder (Left → Root → Right).
  2. Keep a pointer prev = the node visited just before.
  3. At each node, compute root->val - prev->val.
  4. Keep the smallest one in minimum.
  5. Set prev = root and continue.

The smallest gap between sorted numbers is always between neighbours. That is all this algorithm checks.

5 · Complexity

n = number of nodes. h = height = number of levels from the top node down to the deepest node.

Time O(n): every node is visited exactly once, and each visit does one subtraction and one comparison.

Space O(h): we create no list. Only the recursion call stack uses memory, and it holds at most one call per level (plus one last nullptr call).

Balanced · n = 7, h = 3

Stack never deeper than ~3 calls → O(log n).

Skewed (a “stick”) · n = 4, h = 4

Stack as deep as the node count → worst case O(n).
