Algorithm in plain English

  1. Sort the array.
  2. Choose nums[i] as the first number.
  3. Put j immediately after i.
  4. Put k at the end.
  5. Calculate the sum.
  6. If sum < 0 → move j right.
  7. If sum > 0 → move k left.
  8. If sum == 0 → save triplet.
  9. Move j and k inward.
  10. Skip duplicate values.
  11. Repeat.

Complexity (how much work?)

Sorting
O(n log n)
Outer loop (i)
O(n)
j and k per i
O(n) — together they walk the array once, never backwards
Overall
O(n²). Sorting is small next to n × n.

Space: extra working space is O(1) (just i, j, k, sum, n). The returned res itself grows with the number of triplets found, which is the answer, not overhead.

Beginner notes: vector<vector<int>> is a list of lists. nums.begin()/nums.end() are "iterators": markers for the start and one-past-the-end of the array, so sort knows what range to sort. continue means "abandon this loop round and jump to the next i".
