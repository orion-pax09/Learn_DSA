Difficult syntax, in plain words

vector<int>& vis

The & means "reference": the function works on the original vector, not a copy. This is why every recursive call shares one vis. Without it, each call would change a private copy and DFS would forget where it has been.

vector<vector<int>> adj(n)

A vector whose elements are vectors: a list of lists. adj(n) creates n empty inner vectors, so adj[2] is the neighbour list of city 2. (isConnected has the same type but holds a matrix of 0s and 1s.)

for (int neighbor : adj[node])

Range-based for: take each element of adj[node] one at a time and call it neighbor. No index needed.

Recursion

dfs calls dfs. Each call gets its own node and its own place in the loop, stacked on the call stack. return ends only the current call; the caller continues after its call line.
