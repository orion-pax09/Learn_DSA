You answered every knowledge check. BFS recipe: seed the queue with all sources → pop one → check 4 neighbors with bounds first → mark visited immediately → push with time+1 → verify nothing is left unreached.

Common Bugs to Avoid

Complexity

Time O(n × m). Every cell is pushed at most once (it turns rotten the moment it is pushed, so it can never be 1 again). Each popped cell does exactly 4 neighbor checks, so the work is about 4·n·m plus the initial n·m scan.

Space O(n × m). In the worst case (for example a grid full of rotten oranges) the queue holds every cell. The grid itself is modified in place, so no extra visited array is needed.
