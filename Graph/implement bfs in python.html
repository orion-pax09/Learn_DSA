1. The idea, before the code

The friends analogy

You are exploring a social network, starting with one person.

1. Visit the starting person.
2. Visit all their direct friends.
3. Then visit friends of those friends.
4. Keep going outward, one level at a time.

You never jump to a far-away person before finishing everyone closer.

The queue: First In, First Out (FIFO)

Think of a line at a shop. The person who arrived first is served first.

back ← inCBAout → front

A was added first, so A leaves first. That is FIFO, and it is what makes BFS go level by level.

queue vs visited

queue = people waiting to be explored (found, but not processed yet).

visited = people we have already processed, in the order we processed them. This list is the answer.

4. Small visual lessons

Why check both conditions?

Look at E and F. When we process C, F goes in the queue. Later, when we process E, F is a neighbor again. neighbor not in queue stops F from being added twice.

Once F has been processed, neighbor not in visited stops us from going back to it. Example: when processing F, its neighbors C and E are already visited, so both are skipped. Without both checks we would get duplicates and loop forever on cycles.

Why sort neighbors?

Neighbors live in a set, and sets do not promise any order. sorted(...) gives alphabetical order, so the result is always the same: ["A","B","C","D","E","F"]. The assignment requires it. Try turning sorting off in the playground below.

Why queue.pop(0)?

pop(0) removes and returns the first item (index 0), so the oldest waiting vertex goes next. That is FIFO. It is easy to understand for this assignment, but every pop(0) shifts the whole list, which is slow for big queues. collections.deque with popleft() is faster.

Why level by level?

Distance from A: A = 0; B, C = 1; D, E, F = 2. The queue always holds closer vertices in front of farther ones, so all distance-1 vertices leave before any distance-2 vertex. Tick Show levels in the visualizers to see distances. Sorting decides the order inside a level.
