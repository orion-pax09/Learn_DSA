    Pointers, explained simply

    Think of a pile of plates. You only add or remove a plate on the top. Each plate (node) has a number written on it and a sticky note saying where the plate below it is. topNode is your finger resting on the top plate. NULL means "nothing below: the table".

    Three different things: the pointer variable (topNode, temp, newNode, next: they only store addresses), the node (the box in memory), and the data (the number inside the box).

    What is a Node?One plate. It stores one number (data) and one pointer (next) to another node.
    What does Node* next mean?next is a variable that holds the address of another Node, not the Node itself. It is the sticky note saying where the next plate is.
    What does Node* topNode mean?The same kind of variable, stored in the Stack. It holds the address of the first (top) node, or NULL when the stack is empty.
    What does Node* newNode = new Node(val) do?It asks the computer for memory for one Node, runs the constructor (data = val; next = NULL;), and gives back the node's address. newNode stores that address.
    What does -> mean?"Follow the pointer, then use the member." topNode->data means: go to the node topNode points to and read its data.
    What is NULL?A special address meaning "points to nothing". It marks the end of the chain and the empty stack. Never follow it with ->.
    Why do we use temp in pop()?After topNode moves, nothing else points to the old top node. temp keeps its address so we can still delete it. Without temp the node would be lost forever (a memory leak). The value is saved in val first because after delete the data is gone.
    What does delete temp do?It gives the node's memory back to the computer. temp still holds the old address (a "dangling pointer"), but you must not use it again.
    Why does topNode = topNode->next remove the first node?A stack is only reached through topNode. Once it points to the second node, the first node is no longer part of the stack. delete temp then frees it.

    Time complexity

    OperationTimeReason
    push()O(1)Insert at the head
    pop()O(1)Remove from the head
    top()O(1)Read the head node

    Each operation touches only the first node and a few pointers, so the stack's size never changes the work. An array stack needs a fixed capacity chosen up front; this one allocates one node at a time with new, so it grows as needed. Memory is still limited: new fails when the computer runs out, and each node also stores a pointer.
