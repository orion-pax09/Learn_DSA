1. First, the big idea

The string has * characters. A star can be (, ) or nothing. So we are never sure how many ( are still waiting to be closed. Instead of guessing, we keep a range of possible answers:

minimum = the smallest number of unmatched ( that could exist right now.
maximum = the largest number of unmatched ( that could exist right now.

Drag the sliders and see what the range means:

Your code only has to update these two numbers for each character. Here are the three rules you will see in the code:

(
It is definitely open.
max +1, min +1
)
It closes one open (.
max −1, min −1 (min never below 0)
*
It is a joker: (, ) or empty.
max +1, min −1 (min never below 0)
